# 합창단 청음·연습 게임

Jay가 활동하는 아마추어 합창단 단원들이 휴대폰 브라우저에서 바로 청음과 파트 연습을 할 수 있게 만드는 게임 모음입니다.

- **상태**: 시범 단계. 1번 *기준음 청음 게임*이 동작합니다.
- **형태**: 웹페이지 하나 (앱 설치 없음, 아이폰 사파리에서 동작)

---

## 지금 할 수 있는 것: 기준음 청음 게임

기준음 **도(C4)**를 먼저 들려준 뒤 문제 음을 들려줍니다. 화면의 건반에서 어떤 음이었는지 고릅니다.

| 단계 | 내용 |
|---|---|
| 1 | 한 음 · 흰 건반 |
| 2 | 한 음 · 반음(♯) 포함 |
| 3 | 두 음 · 흰 건반 |
| 4 | 두 음 · 반음 포함 |
| 5 | 세 음 · 반음 포함 |
| 6 | 네 음 · 반음 포함 |

- 한 판은 10문제이고, **8문제 이상** 맞히면 다음 단계가 열립니다.
- 음역은 도부터 높은 도까지 한 옥타브입니다.
- 답하는 동안에는 건반을 눌러도 소리가 나지 않습니다(귀로만 맞히기). 채점이 끝나면 건반을 눌러 소리를 비교해 볼 수 있습니다.
- 화면 위의 **음 계단** 그림에서 기준음과 문제 음의 높낮이 흐름을 보여 줍니다.
- 정답이면 작은 **폭죽 소리**, 오답이면 아쉬워하는 **한숨 소리**가 납니다. 문제 음역과 겹치지 않게 만들었고, 게임 화면 위쪽 버튼으로 끌 수 있습니다.
- 진행 기록은 그 브라우저에만 저장됩니다.
- 컴퓨터에서는 Enter(확인·다음), Backspace(지우기), R(다시 듣기) 키도 쓸 수 있습니다.

### 실행 방법

| 파일 | 설명 |
|---|---|
| `index.html` | **온라인 버전**. p5 라이브러리를 CDN에서 불러옵니다. 웹에 올려서 쓰는 기본 버전입니다. |
| `local.html` | **로컬 버전**. 함께 들어 있는 `lib/p5.min.js`를 써서 인터넷 없이도 돌아갑니다. 폴더를 통째로 받아 이 파일을 브라우저로 열면 됩니다. |

웹에 올리려면 GitHub Pages(저장소 Settings → Pages → `main` 브랜치)를 켜면 `index.html`이 바로 열립니다.

### 사용 안내 (단원용)

- 🎧 **이어폰 착용**을 권장합니다.
- 아이폰에서 소리가 안 나면 **무음 모드를 끄고** 볼륨을 올려 주세요.

## 파일 구성

```
index.html      온라인 버전 (p5: CDN)
local.html      로컬 버전 (p5: lib/)
game.js         게임 로직, 소리 합성(Web Audio), 음 계단 그림(p5)
style.css       화면 스타일 (밝은/어두운 모드)
lib/p5.min.js   p5.js 1.9.4 (LGPL-2.1, lib/p5-LICENSE.txt)
```

소리는 음원 파일 없이 Web Audio로 직접 합성합니다.

## 게임 아이디어 목록

### Jay 아이디어

1. **기준음 청음** ✅ 시범 완료: 기준음을 들려주고 문제 음을 맞힌다. 반음까지 포함하고, 음의 개수를 늘려 가며 단계별로 어렵게 한다.
2. **악보 따라 부르기**: 악보 일부(가사가 있으면 함께)를 보여 주고 연주를 들려준 뒤 따라 부르게 한다. 녹음해서 음정과 박자가 얼마나 정확한지 평가한다. 마디 수, 어려운 박자, 어려운 음정으로 난이도를 올린다.
3. **박자 따라 하기**: 들려준 박자에 맞춰 버튼을 누른다.

### 제안 아이디어 (Fullo)

4. **화음 청음**: 3화음의 장조·단조 구별, 화음 속에서 알토나 베이스 음 하나만 골라 부르기.
5. **내 파트 지키기**: 다른 파트(소프라노·알토·테너·베이스)를 틀어 놓고 내 파트를 불러 음정이 끌려가지 않았는지 평가.
6. **첫 음 잡기**: 기준음 하나만 듣고 내 파트의 첫 음을 바로 낸다.
7. **음 유지와 화음 맞추기**: 길게 낸 음이 처지는지 그래프로 보여 주고, 화음 속에서 잘 어울렸는지 점수로 보여 준다.
8. **계명창 읽기**: 연주 없이 악보 몇 마디를 바로 부른다. 마디 수와 조표로 난이도를 올린다.
9. **쉼표와 들어가는 박**: 쉼표 뒤 정확한 박에 들어가기, 지휘 박에 맞춰 시작하기.
10. **가사 발음 맞추기**: 파트끼리 자음을 끝내는 타이밍을 맞춘다.
11. **단원 대항전**: 주간 점수판과 파트별 순위.

## 기술 메모

- **웹페이지 하나**로 만든다. 앱 설치 없이 아이폰 사파리에서도 돌아간다. 연주를 들려주면서 동시에 녹음할 수 있다.
- **이어폰 착용을 기본으로 안내**한다. 스피커로 틀면 반주 소리가 마이크에 섞이고, 에코 제거 기능은 노래 소리까지 깎는다.
- **블루투스 이어폰 지연**(0.1~0.3초)은 처음에 한 번 재서 보정한다.
- **악보 저작권**: 처음에는 저작권이 끝난 곡이나 합창단이 직접 가진 연습 자료만 쓴다.
- **시각화는 p5**를 쓴다. 온라인 버전을 기본으로 하고, 라이브러리를 넣은 로컬 버전도 함께 만든다.
