# 합창단 청음·연습 게임

Jay가 활동하는 아마추어 합창단 단원들이 휴대폰 브라우저에서 바로 청음과 파트 연습을 할 수 있게 만드는 게임 모음입니다.

- **상태**: 시범 단계. 1번 *기준음 청음*, 4번 *화음 청음*, 3번 *박자 따라 하기*, 6번 *첫 음 잡기*가 동작합니다.
- **사이트**: https://love540.github.io/choir-pitch-game/
- **형태**: 웹페이지 하나 (앱 설치 없음, 아이폰 사파리에서 동작)

---

## 지금 할 수 있는 것

첫 화면에서 게임을 고르고, 단계별로 연습합니다.

### 🎯 기준음 청음 (1번)

기준음 **도(C4)**를 먼저 들려준 뒤 문제 음을 들려줍니다. 화면의 건반에서 어떤 음이었는지 고릅니다.

| 단계 | 내용 |
|---|---|
| 1 | 한 음 · 흰 건반 |
| 2 | 한 음 · 반음(♯) 포함 |
| 3 | 두 음 · 흰 건반 |
| 4 | 두 음 · 반음 포함 |
| 5 | 세 음 · 반음 포함 |
| 6 | 네 음 · 반음 포함 |

### 🎶 화음 청음 (4번)

세 음이 함께 울리는 3화음을 듣고 화음의 종류를 구별하거나, 화음 속 한 음을 찾습니다.

| 단계 | 내용 |
|---|---|
| 1 | 장조·단조 · 펼친 화음 (한 음씩 들려준 뒤 함께 울림) |
| 2 | 장조·단조 (함께 울리는 화음만) |
| 3 | 장·단·감·증 3화음 구별 |
| 4 | 베이스 음 찾기 (가장 낮은 음) |
| 5 | 소프라노 음 찾기 (가장 높은 음) |
| 6 | 가운데 음 찾기 (알토) |
| 7 | 🎤 베이스 음 부르기 (화음만 듣고 가장 낮은 음) |
| 8 | 🎤 소프라노 음 부르기 (가장 높은 음) |
| 9 | 🎤 가운데 음 부르기 (자리바꿈 화음에서 알토처럼 가운데 음) |

- 1~3단계는 "밝은 소리 / 어두운 소리" 같은 보기에서 고릅니다. 채점 후 보기를 누르면 같은 바닥음으로 그 화음을 들려줘서 비교할 수 있습니다.
- 4~6단계는 기준음 도를 먼저 들려준 뒤 화음을 들려주고, 건반에서 고릅니다. 자리바꿈 화음도 섞여 나옵니다.
- 채점 후 음 계단 그림에 화음의 세 음과 화음 이름이 나옵니다.
- 7~9단계는 **화음만 듣고 고른 성부의 음을 부릅니다**. 첫 음 잡기와 같은 방식으로 마이크로 음정을 재고(±50센트, 옥타브 상관없음, 녹음 저장 안 함), 채점 전에는 목표 음 이름을 숨깁니다. 화음의 다른 음을 부르면 "화음의 가운데 음(파♯)을 불렀어요"처럼 알려 줍니다.

### 🥁 박자 따라 하기 (3번)

예비박 4번 → 리듬 듣기 → 이어지는 메트로놈에 맞춰 큰 버튼으로 똑같이 치기 → 자동 채점.

| 단계 | 내용 | 빠르기 |
|---|---|---|
| 1 | 4분음표 · 2분음표 | ♩=80 |
| 2 | 8분음표 | ♩=80 |
| 3 | 쉼표 (4분쉼표, 8분쉼표) | ♩=80 |
| 4 | 점4분음표 + 8분음표 | ♩=76 |
| 5 | 16분음표 | ♩=70 |
| 6 | 당김음 · 두 마디 | ♩=80 |

- 놓친 박이나 남는 탭이 없으면 정답입니다. 박마다 맞게 친 범위는 최대 ±0.15초이고, 빠른 리듬에서는 이웃한 음과 헷갈리지 않게 더 좁아집니다.
- 평균 몇 ms 차이였는지, 서두르는 편인지 늦는 편인지 알려 줍니다.
- **큰 버튼이 박자 안내판**입니다. 지금 단계(예비박 / 👂 듣기 / 👏 따라 치기)와 박 번호 1·2·3·4가 메트로놈에 맞춰 켜집니다(이어폰 지연만큼 늦춰서 귀에 들리는 순간에 맞춤).
- 위 그림은 처음부터 끝까지 같은 틀입니다(박 번호, "정답" 줄, "나" 줄). 듣는 동안에는 "정답" 줄에 재생 위치만 보이고(리듬 모양은 귀로 듣는 연습이라 숨김), 따라 칠 때는 "나" 줄에 누른 곳이 바로 찍힙니다.
- 채점 후 "🔁 다시 해 보기 (연습)"으로 같은 리듬을 다시 칠 수 있습니다. 점수에는 첫 시도만 들어갑니다.
- 채점 후에는 **정답 리듬을 음표**(♩ ♪, 빔, 점음표, 쉼표)로 그리고, 바로 아래 같은 줄에 내가 친 위치를 표시합니다. 초록 정확(±60ms), 주황 조금 어긋남("빠름"/"늦음"), ✕ 놓침, 빨강 남는 탭.
- 컴퓨터에서는 스페이스 키로도 칠 수 있습니다.

**⏱ 이어폰 지연 맞추기**: 블루투스 이어폰은 소리가 0.1~0.3초 늦게 들립니다. 딸깍 소리 12번에 맞춰 누르면 지연을 재서 박자 채점에 반영합니다. 이어폰을 바꾸면 다시 합니다. 안 했을 때는 브라우저가 알려 주는 지연 값을 씁니다.

### 🎤 첫 음 잡기 (6번)

기준음 하나만 듣고 목표 음(예: "솔")을 바로 부릅니다. 마이크로 음정을 재서, 음이 0.4초 동안 흔들리지 않는 첫 구간이 목표 음에서 몇 센트 벗어났는지 채점합니다.

| 단계 | 내용 | 정답 범위 |
|---|---|---|
| 1 | 기준음 도 → 같은 음 | ±50센트 |
| 2 | 기준음 도 → 도, 미, 솔 | ±50센트 |
| 3 | 기준음 도 → 레~시 (흰 건반) | ±50센트 |
| 4 | 기준음 도 → 반음 포함 | ±50센트 |
| 5 | 여러 기준음에서 위아래 음 | ±50센트 |
| 6 | 5단계 + 기준음 뒤 2초 쉬고 부르기 | ±30센트 |

- 100센트 = 반음입니다. ±50센트면 "그 음으로 들리는" 정도, ±30센트면 합창에서 어울리는 정도입니다.
- **옥타브는 상관없습니다.** 같은 이름의 음이면 정답이라, 남성 파트는 한 옥타브 낮게 불러도 됩니다.
- 6초 안에 음이 잡히지 않으면 점수 없이 다시 시도합니다.
- 채점 후 그림에 부른 음정의 흐름이 나오고, "정답 음 듣기"로 기준음과 목표 음을 이어서 들을 수 있습니다.
- **녹음은 저장하지 않습니다.** 마이크 소리에서 그때그때 음 높이만 재고 버립니다.
- 에코 제거·잡음 제거·자동 음량을 끄고 마이크를 받습니다(노래 소리가 깎이지 않게). 기준음이 끝나고 0.5초 뒤부터 듣기 때문에 스피커로도 할 수 있지만, 이어폰을 권합니다.
- 처음 한 번 브라우저가 마이크 허용을 묻습니다. 아이폰에서 거절했다면 설정 → Safari → 마이크에서 바꿀 수 있습니다.

### 공통

- 한 판은 10문제이고, **8문제 이상** 맞히면 다음 단계가 열립니다.
- 음역은 도부터 높은 도까지 한 옥타브입니다.
- 답하는 동안에는 건반을 눌러도 소리가 나지 않습니다(귀로만 맞히기). 채점이 끝나면 건반을 눌러 소리를 비교해 볼 수 있습니다.
- 화면 위의 **음 계단** 그림에서 기준음과 문제 음의 높낮이 흐름을 보여 줍니다.
- 정답·오답 **효과음**이 납니다. 문제 음역과 겹치지 않게 만들었고, 게임 화면 위쪽 버튼으로 끌 수 있습니다.
- 진행 기록은 그 브라우저에만 저장됩니다.
- 컴퓨터에서는 Enter(확인·다음), Backspace(지우기), R(다시 듣기), 스페이스(박자 치기) 키도 쓸 수 있습니다.

### 실행 방법

| 파일 | 설명 |
|---|---|
| `index.html` | **온라인 버전**. p5 라이브러리를 CDN에서 불러옵니다. 웹에 올려서 쓰는 기본 버전입니다. |
| `local.html` | **로컬 버전**. 함께 들어 있는 `lib/p5.min.js`를 써서 인터넷 없이도 돌아갑니다. 폴더를 통째로 받아 이 파일을 브라우저로 열면 됩니다. |

웹에 올리려면 GitHub Pages(저장소 Settings → Pages → `main` 브랜치)를 켜면 `index.html`이 바로 열립니다.

**주소는 항상 https://love540.github.io/choir-pitch-game 하나만 씁니다.** 새 버전을 배포할 때는 아래 세 곳의 숫자를 함께 올립니다. 그러면 이미 열어 둔 휴대폰에서도 다음에 열거나 돌아올 때 스스로 새 버전으로 바뀝니다(사파리 캐시 대비).

- `version.json`의 `version`
- `game.js`의 `APP_VERSION`
- `index.html`, `local.html`의 `?v=` 숫자

### 사용 안내 (단원용)

- 🎧 **이어폰 착용**을 권장합니다.
- 아이폰에서 소리가 안 나면 **무음 모드를 끄고** 볼륨을 올려 주세요.

## 파일 구성

```
index.html      온라인 버전 (p5: CDN)
local.html      로컬 버전 (p5: lib/)
game.js         게임 로직(기준음 청음, 화음 청음, 박자 따라 하기, 첫 음 잡기), 소리 합성(Web Audio), 음 높이 측정(YIN), 그림(p5)
style.css       화면 스타일 (밝은/어두운 모드)
lib/p5.min.js   p5.js 1.9.4 (LGPL-2.1, lib/p5-LICENSE.txt)
audio/piano/    그랜드 피아노 녹음 10개 (낮은 도~높은 레♯, 3반음 간격, 각 3.5초)
audio/piano-data.js  위 녹음을 묶은 파일 (tools/make_piano_data.py로 만듦)
version.json    배포 버전 (열려 있는 페이지가 새 버전을 알아채는 데 씀)
```

### 소리

- **피아노**: 실제 그랜드 피아노 녹음(Salamander Grand Piano V3, 야마하 C5)을 씁니다.
  - 3반음 간격 녹음 10개만 넣고, 사이 음은 가까운 녹음을 조금 빠르게/느리게 재생합니다(최대 ±1반음).
  - 실제 피아노는 건반마다 조율이 조금씩 다르므로(높은 음은 최대 14센트 높게 조율됨), 불러올 때 녹음마다 음높이를 재서 바로잡습니다. 게임에서 쓰는 모든 음이 평균율에서 2센트 이내입니다.
  - 원본 녹음은 16초짜리라 앞 무음을 자르고 3.5초에서 페이드아웃해 줄였습니다(합계 약 520KB).
  - 녹음을 불러오기 전(첫 순간)이나 불러오지 못하면 합성음으로 냅니다.
- **효과음·메트로놈**: Web Audio로 직접 합성합니다.

**출처 표기**: 피아노 소리 — Salamander Grand Piano V3, Alexander Holm, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) ([원본](https://archive.org/details/SalamanderGrandPianoV3), npm `@audio-samples/piano-mp3-velocity8` 의 velocity 8 녹음). 앱 첫 화면 아래에도 표기합니다.

## 게임 아이디어 목록

### Jay 아이디어

1. **기준음 청음** ✅ 시범 완료: 기준음을 들려주고 문제 음을 맞힌다. 반음까지 포함하고, 음의 개수를 늘려 가며 단계별로 어렵게 한다.
2. **악보 따라 부르기**: 악보 일부(가사가 있으면 함께)를 보여 주고 연주를 들려준 뒤 따라 부르게 한다. 녹음해서 음정과 박자가 얼마나 정확한지 평가한다. 마디 수, 어려운 박자, 어려운 음정으로 난이도를 올린다.
3. **박자 따라 하기** ✅ 완료: 들려준 박자에 맞춰 버튼을 누른다.

### 제안 아이디어 (Fullo)

4. **화음 청음** ✅ 완료 (듣고 고르기 + 부르기): 3화음의 장조·단조 구별, 화음 속에서 알토나 베이스 음 하나만 골라 부르기.
5. **내 파트 지키기**: 다른 파트(소프라노·알토·테너·베이스)를 틀어 놓고 내 파트를 불러 음정이 끌려가지 않았는지 평가.
6. **첫 음 잡기** ✅ 완료: 기준음 하나만 듣고 내 파트의 첫 음을 바로 낸다.
7. **음 유지와 화음 맞추기**: 길게 낸 음이 처지는지 그래프로 보여 주고, 화음 속에서 잘 어울렸는지 점수로 보여 준다.
8. **계명창 읽기**: 연주 없이 악보 몇 마디를 바로 부른다. 마디 수와 조표로 난이도를 올린다.
9. **쉼표와 들어가는 박**: 쉼표 뒤 정확한 박에 들어가기, 지휘 박에 맞춰 시작하기.
10. **가사 발음 맞추기**: 파트끼리 자음을 끝내는 타이밍을 맞춘다.
11. **단원 대항전**: 주간 점수판과 파트별 순위.

## 기술 메모

- **웹페이지 하나**로 만든다. 앱 설치 없이 아이폰 사파리에서도 돌아간다. 연주를 들려주면서 동시에 녹음할 수 있다.
- **이어폰 착용을 기본으로 안내**한다. 스피커로 틀면 반주 소리가 마이크에 섞이고, 에코 제거 기능은 노래 소리까지 깎는다.
- **블루투스 이어폰 지연**(0.1~0.3초)은 처음에 한 번 재서 보정한다.
- **악보 저작권**: 처음에는 저작권이 끝난 곡이나 합창단이 직접 가진 연습 자료만 쓴다.
- **시각화는 p5**를 쓴다. 온라인 버전을 기본으로 하고, 라이브러리를 넣은 로컬 버전도 함께 만든다.
